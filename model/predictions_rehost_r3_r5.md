## What exists now (all before any stage 1 loop run)

Check rules L1 to L6 (one backward branch to the NOP before TTUOPEN, bounded rounds, stores and loads through known pointers, one session in the binary).
- Stage 0 (no TTU instruction, group slots are NOPs) with fake candidates injected through the input registers: 512 lanes, radii 0.1 to 0.8, five seeds: every count and neighbour id equals the host's float32 expression (0 mismatches). - ttu/rehost/rtnn_host.cu: data points (uniform in the unit cube), AABB GAS (box = point +- r), an OptiX reference pipeline (rtnn_dev.cu) whose intersection program uses the same float expression and records the neighbours in call order, CPU grid search with the same expression, the register images, the patched kernel launch, events timing.
- ttu/rehost/rtnn_run.py: check_seq marker, who and nvidia-smi logged and no process on any GPU, timeout -k 2 30, mode x raw files.
