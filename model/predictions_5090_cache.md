# Cache_1 (F202 program) and Memory_1 plain chase on the RTX 5090: predictions, written 2026-11-19 BEFORE these runs (addition to model/predictions_5090.md)

The first prediction file (predictions_5090.md, commit a8b9e46) covers the pointer chase and the Memory_1 L1 numbers (items 1 and 8) and had no line for the F202 cache program (ttu/bench/Cache_1, modes l1cap, l1sect, l2lat). These are added now, before any 5090 timing of any cache mode. Basis: F202 (4090) and F203 (6000 Ada), which agree with each other; Ada constants as the null hypothesis for the 5090 (a different architecture, so ranges are wide). Disclosure: no 5090 timing of any kind has been taken at this point except the configuration probes (block placement, SM ids).

1. l1sect (1 MB array, stride sweep): sector 32 bytes. Sequential order: cycles per load rise with stride as the miss fraction stride / 32 (about 70 / 100 / 160 / 290 at stride 4 / 8 / 16 / 32 on the 4090; I predict the same shape with the L2 hit near 290, range 250 to 340); random order: every stride at the L2 hit latency (290, range 250 to 340). p = 0.75 that the 32 byte sector shows (miss fraction = stride / 32 up to 32).
2. l1cap (stride 128, sequential cyclic, no shared memory in use): knee between 80 and 128 KB with a soft edge (4090: 88 to 124 KB, effective about 96 KB), p = 0.6. Tag line 128 bytes: the knee footprint at stride 32 and 64 is within 10 percent of the stride 128 one, p = 0.55.
3. l2lat (16 MB, .cg, random order, one SM): one latency mode, median 320 (range 270 to 380) on the 5090, 95 percent of the lines within 15 percent of the median, p = 0.55; graded per line latency (no near and far split) p = 0.6. (4090: 291 to 352 graded, median 325 on the 6000 Ada.)
4. Memory_1 plain chase (stride 128 lines, .ca, 16 to 160 KB, with 0 and 98,304 bytes of shared memory reserved): without the reservation the L1 hit (about 41) holds up to about 80 KB and the latency is at the L2 value by 128 KB; with the reservation the L1 hit holds only to a size between 16 and 32 KB (L1 about 20 KB, range 16 to 32 KB), p = 0.6.
Reading rules: a range or a value counts as held when the measurement is inside it; the knee is the footprint where the latency is halfway between the L1 hit and the L2 hit.
Safety: plain CUDA only, no TTU instruction, GPU 0 checked with notes/pc14_gpucheck.sh before every process, timeout -k 2 30, smallest first.
